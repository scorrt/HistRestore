# Data and Code Availability

This repository provides the HistRestore implementation, final split manifests, compound-proxy generation script and configuration, candidate-bank definitions, source-candidate evidence and VCCRP implementation, Prompt A–E templates, Qwen label mapping, coefficient-sensitivity outputs, OCR diagnostic matrices, runtime measurements, and per-page Historical-537 evaluation files.

The image datasets and third-party restoration models used in the study are obtained from the original providers cited in the manuscript and remain subject to their respective licenses. The released manifests and result tables identify the protocol used for the reported experiments.
